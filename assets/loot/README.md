# Loot art sources

These transparent PNGs are source art for the existing gameplay loot tiers.
They are not uploaded Roblox decals yet; an upload needs Chris's account and a
final asset ID before game code can reference them.

| File | Gameplay use |
| --- | --- |
| `relic-access-device-concept-v1.png` | Visual target for the lantern-only `Relics` tier. It should read as dormant in darkness and catch cyan lantern light when revealed. |
| `restoration-crate-concept-v1.png` | Visual target for `RestorationCrates`, the bulky tier that occupies the carry slot and feeds Lanternhold landmarks. |

Both are original project source assets with no external store or mall branding.
